# 📸 SnapSpace – Image Gallery Website

**Capture Moments. Explore Creativity. Discover Inspiration.**

SnapSpace is a modern and visually appealing image gallery website developed using HTML, CSS, and JavaScript. It provides an attractive platform to explore and view images through a clean, organized, and user-friendly interface.

---

## 🌟 Project Overview

SnapSpace is a frontend web development project focused on creating an engaging image browsing experience. The website combines modern design, attractive layouts, and interactive elements to present images beautifully.

## 🚀 How to Run Locally

1. Clone the repository:

   git clone https://github.com/karthimuru3528/CodeAlpha_Image-Gallery

2. Open the project folder in VS Code.

3. Open `index.html` in your browser.

4. Alternatively, use the Live Server extension in VS Code.
